📅 第4周: MQ改造

为什么需要消息队列?

❌ HTTP直连问题: 同步阻塞、耦合度高、峰值压力大
✅ MQ优势: 异步解耦、削峰填谷、可靠传输、可扩展

Redis Streams

Stream列表: sensor:raw → sensor:validated → sensor:write → sensor:logs

四大模块

  • module_receiver.py: 从MQ读取原始数据
  • module_validator.py: 验证数据合理性
  • module_writer.py: 写入MongoDB/文件
  • module_logger.py: 异步日志记录
