## 🐛 常见问题

### 问题1：页面空白
**原因**：API请求失败或数据为空  
**解决**：
```bash
# 检查服务器状态
ssh root@47.103.108.47 "systemctl status flask-data-server"

# 查看Console日志
打开微信开发者工具 Console 标签
```

### 问题2：图标不显示
**原因**：tabBar图标路径不存在  
**解决**：
```
暂时移除app.json中的iconPath配置
或使用emoji代替图标
```

### 问题3：数据不更新
**原因**：缓存问题  
**解决**：
```
1. 下拉刷新
2. 清除缓存：工具 → 清除缓存 → 全部清除
3. 重新编译
```
